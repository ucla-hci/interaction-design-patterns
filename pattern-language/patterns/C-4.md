## Solution

1. Make a canvas the working state. Keep it for the whole session.
2. Draw each item as a card with a label and a summary. Add a status line when items change state.
3. Link each item to the item that it comes from. State what a node and a link mean.
4. Choose the shape: a tree from a root, or a network when items have no single origin.
5. When a link carries a score, show it on the link (C-8). When marks encode criteria, show a legend.
6. When the user selects an item, mark it and open Detail on Demand (C-6).

## States

One state. The map grows as items arrive.
