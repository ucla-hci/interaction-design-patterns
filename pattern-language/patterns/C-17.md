## Solution

Give every item of one kind the same fields, in the same order. Show empty fields as empty.

Variation: the user chooses the kind of each item from a fixed list, and a colour marks the kind.

## Examples

- PerspectEvolver Perspective Card, six fields
- THESEUS sub-hypothesis, typed fields
- IdeaSynth facet node: four kinds, title and content
