## Example

- `figures/C-10/1-halo.png` HALO Fig. 2, callout C: strategies in two groups; each has a rationale and an edit action

The options answer an item (the molecule HALO-113: 2 strategies). Each option has a label (1.
Replace N-methyl with benzyl to increase lipophilicity), a summary, and a rationale (Targets
plogp). Each option links to the item that it comes from (HALO-113). The options are grouped by
kind (intra-cluster, inter-cluster), and each one shows before → after (the fragment that it
changes). The apply action is on the item, not on each option (Edit molecule).

## Solution

1. Show a few options together, three in most cases. State what they answer: an item, a result, or a question.
2. Give each option a label, and a summary or a rationale.
3. Link each option to the item that it comes from (C-14).
4. When the options are of different kinds, group or tag them by kind.
5. Put an apply action on each option. The user applies one option.
6. When the options come from open items, show them unopened. Draw the unopened state apart.

Variation: the system puts all the options on the map, each one linked to its origin. The user deletes the options that are not wanted.
