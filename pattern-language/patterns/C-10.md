## Solution

Show a few labelled options, each one with its rationale. The user applies one option. When the options come from open items, show them unopened.

Variation: the system puts all the options on the map, each one linked to its origin. The user deletes the options that are not wanted.

## Examples

- HALO strategy list
- THESEUS 3 candidates
- PerspectEvolver proposals
- PerspectEvolver suggested threads
- THESEUS follow-up directions
- IdeaSynth node suggestions, three kinds
