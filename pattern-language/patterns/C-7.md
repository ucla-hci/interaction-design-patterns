## Solution

Store the rationale and the sources on the item or the link that they justify. Open them from there.

## Examples

- THESEUS node and edge rationale
- PerspectEvolver per-field evidence
- HAPPIER papers per PPI
- HALO cluster explanation
- IdeaSynth paper sections per node
