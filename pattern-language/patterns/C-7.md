## Example

- `figures/C-7/4-theseus.png` THESEUS Fig. 2, callout C: decomposition rationale; papers used, each one opens

The evidence opens in a panel beside the selected item (a sub-hypothesis; outside this crop). The
rationale is prose (decomposition rationale). The sources are a list (papers used). Each source
has a title, metadata (2024, semantic_scholar), and an open control (Open paper). A count shows
the number of sources (2 used, 18 retrieved). Each kind of evidence is a section that collapses.

## Solution

1. Store the rationale and the sources on the item or the link that they justify.
2. Open them from that item, in a panel beside it (C-6). Name the item that they justify.
3. Give the rationale in prose, or in labelled fields (for example, strengths and weaknesses).
4. List the sources: a title, metadata, and an open control for each. Show a count of the sources.
5. When the evidence is data and not a source, show it as a table or a visualization.
6. Put each kind of evidence in a section that collapses.

## Examples

- THESEUS node and edge rationale
- PerspectEvolver per-field evidence
- HAPPIER papers per PPI
- HALO cluster explanation
- IdeaSynth paper sections per node
