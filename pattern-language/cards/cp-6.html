Level
component
Context
A3 Group Candidates by Criteria · A4 Check Candidates Against Every Criterion · B3 Summarize the Discussion · C3 Judge Each Part Against Its Evidence
Goal
The user examines one item without losing the others.
Failure
All the evidence at once overloads the user. Evidence apart from its item is hard to check.
Solution
  1. Show a summary of every item in an overview: a map (CP-4) or a list.
  2. When the user selects an item, mark it in the overview. Open a panel beside the overview.
  3. Keep the overview visible while the panel is open.
  4. In the panel, give the item label, then why the item holds, in prose.
  5. Put the evidence in sections that collapse: sources that open, and tables or visualizations.
  6. When the claim was generated, add a Confidence Cue (CP-8).
  7. Put a keep control in the panel header when the workflow keeps items (CP-12).
States
closed: the overview only → open (drawn): after the user selects an item. Close or select another item to leave it.
References
CP-4 Persistent Structure Map (the overview) · CP-7 Attached Evidence (the sections) · CP-8 Confidence Cue · CP-12 Shortlist (the keep control)
