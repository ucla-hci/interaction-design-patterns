**Survey** → **Approach type**: empirical validation of information-seeking task categories

# One Sentence
Empirically confirms that exploratory and lookup tasks produce measurably different search behavior (query length, browsing patterns, time allocation), validating Marchionini's categories as behaviorally real rather than merely conceptual.

---

# More Sentences
Controlled comparison of user behavior across exploratory and lookup task conditions, identifying behavioral markers that distinguish the two. The importance for taxonomy construction: task categories earn their place by producing measurable behavioral differences, not by conceptual appeal.

---

# Key Points

### Categories must discriminate behavior
The methodological standard this paper sets: a task taxonomy used as an evaluation instrument must show between-category differences on objective measures. The same bar applies to a GenUI task battery — if two "purposes" don't produce different format effects, merge them.

# Take-Away
- Sets the validation criterion for the proposed six-purpose taxonomy: each purpose must show a distinct format-effect signature, or it isn't a real category for this use
