# One Sentence
Re-classifies information-seeking tasks along new dimensions — number of search iterations, search goal types, and procedures to reach goals — and maps machine-learning solutions to each resulting category.

---

# More Sentences
Rather than adding categories, the paper decomposes IS tasks into orthogonal dimensions, arguing that iteration count and goal structure (not topic) determine which computational approach fits. Includes a review of evaluation campaigns for IS systems.

---

# Key Points

### Iterations as a first-class dimension
Single-shot vs. iterated is a structural property of the task, independent of its goal type. For the format question: single-glance formats (dashboard-like GenUI) vs. conversational refinement serve different iteration profiles.

### Goal type × procedure
Separating *what the goal is* from *how it is reached* parallels Brehmer & Munzner's why/how split — the same decomposition move in a different field.
