# One Sentence
A position paper identifying three underacknowledged barriers to GenUI adoption: lack of adaptable data formats, outdated security protocols, and gaps in users' cognitive and creative skills for interface creation.

---

# More Sentences
Cifliku argues that GenUI's promise of democratizing tool creation is partially offset by hidden technical debt in data layer flexibility, security infrastructure, and required user competencies. The paper calls for new evaluation frameworks and scientific approaches to measure malleable software impact empirically. No data or user study is reported.

---

# Key Points

### Three debt categories
(1) Data format limitations — existing formats don't flex for GenUI; (2) Security protocol gaps — current protocols not designed for dynamically generated interfaces; (3) User skill gaps — non-experts lack cognitive/creative competencies to specify and evaluate generated interfaces.

### Critique of evaluation
Current GenUI evaluation methods are insufficient; better empirical frameworks needed to document real-world usage patterns and measure impact. This is an implicit acknowledgment that the "GenUI is better" claim is under-supported empirically.

# Other Notes
Position paper from the CHI 2026 "GenUI Meets HCI" workshop — a venue specifically convened to debate what GenUI means for practice, suggesting the field itself recognizes these questions are unresolved.

# Take-Away
- The expert community in 2026 considers the empirical case for GenUI still incomplete — hence a whole CHI workshop dedicated to the question
- Technical debt concerns are real; they don't negate preference evidence but complicate deployment
