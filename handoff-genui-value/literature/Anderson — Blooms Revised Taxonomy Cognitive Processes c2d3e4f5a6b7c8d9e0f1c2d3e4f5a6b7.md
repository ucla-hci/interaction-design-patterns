# One Sentence
The revised Bloom's taxonomy defines six cognitive processes — remember, understand, apply, analyze, evaluate, create — crossed with four knowledge types, forming the standard instrument for constructing assessment items at controlled cognitive levels.

---

# More Sentences
The revision recast Bloom's nouns as verbs (emphasizing operations) and added the knowledge dimension (factual, conceptual, procedural, metacognitive), yielding a 6×4 matrix. Its enduring value for experimental design: it is the most widely used recipe for *writing test items that isolate a specific cognitive operation* — exactly what a task battery needs.

---

# Key Points

### Verbs = operations on information
Remember ≈ retrieve/locate; understand ≈ comprehend/summarize; apply ≈ act/execute; analyze ≈ decompose/relate; evaluate ≈ judge/decide; create ≈ produce. Near-complete overlap with the provisional six-purpose decomposition — with monitor as the notable absentee (Bloom has no repeated-reference process).

### Item-writing discipline
Decades of psychometric practice on writing questions that hit one level without contaminating others — directly reusable for building comprehension quizzes and decision probes in the format study.

# Take-Away
- Independent (third) convergence on the same set of building-block operations, from education rather than IR or InfoVis
- Practical tool: use Bloom-style item-writing rules to construct the task battery's probes at controlled cognitive levels
